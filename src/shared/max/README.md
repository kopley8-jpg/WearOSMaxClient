# Куда что класть

Скопируй файлы в свой проект так:

```
src/
  compressor.ts     ← уже есть, не трогать (нужен export function Kne)
  secret.ts         ← уже есть, не трогать
  max/
    protocol.ts     ← новый
    audio.ts        ← новый (замена makeVoice.ts)
    client.ts       ← новый
    index.ts         ← новый
  server.ts          ← замена твоего старого socket.ts
```

Старый `socket.ts` можно удалить или переименовать в `socket.old.ts` на всякий
случай — вся его логика (INIT/LOGIN/heartbeat/history/voice/upload) теперь
внутри `MaxClient`.

`App.tsx` трогать не нужно — протокол между браузером и локальным сервером
(`{type: "AUTH"}`, `{type: "SEND_VOICE", path}` и т.д.) не изменился.

Запуск такой же:

```
npx tsx src/server.ts
```

## Что изменилось по сути

- Один класс `MaxClient` вместо кучи глобальных функций и общего счётчика `maxSeq`.
- `request()` сам сопоставляет ответ по `seq`, ошибки `cmd:3` превращаются в
  `reject`, таймаут — как раньше, 30 сек.
- Heartbeat (opcode 1 каждые 25 сек) стартует сам после `connect()` и
  останавливается при `disconnect()`/`close`.
- `wave` в `audio.ts` теперь нормализуется по максимуму конкретного файла, а
  не по абсолютной шкале int16 — тихие голосовые больше не будут давать
  плоскую линию.
- В `convertToOgg` добавлен `-map_metadata -1` (лишняя подстраховка от
  метаданных, не только обложек).
- Загрузка обычных файлов (`sendFile`) и голосовых (`sendVoice`) используют
  разный транспорт: `sendFile` — `fetch` + `FormData` (как раньше), `sendVoice`
  — `curl` с `Content-Range` (тоже как раньше, было проверено на реальном
  сервере). Это сознательно оставлено разным, чтобы не переизобретать то, что
  уже подтверждённо работает.

## Дальше можно добавить в client.ts

- `sendText(chatId, text)` — простой текст без вложений, тем же `request(64, ...)`.
- Параметризовать `DEFAULT_CHAT_ID` в `server.ts` — сейчас чат захардкожен,
  как было в исходном коде.
- Реальный `getMessage`/пагинация истории через `from` (уже поддержано в
  сигнатуре `getHistory`, просто не используется в `server.ts`).
